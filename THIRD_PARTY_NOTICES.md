## Bundled data

Unlike the tools and libraries above, this catalog is **shipped inside seestar** (it is not
installed separately), so it carries its own attribution:

| Data | Role | License | Project |
|---|---|---|---|
| **OpenNGC** (pinned release **v20260501**) | Source identity/coordinates for the known-target catalog | CC-BY-SA-4.0 | https://github.com/mattiaverga/OpenNGC |

`seestar/data/known_targets.json` is generated by `tools/build_known_targets.py` from the
integrity-pinned OpenNGC release directory `tools/data/openngc-v20260501/` and the
exception-only `target_curation.yaml`. The runtime subset covers the deduplicated Messier and
Caldwell catalogs; it is not a bulk runtime import of OpenNGC. Catalog coordinates, types,
extents, and derived footprints come from the pinned source, while the small number of
curated morphology traits and relationship annotations are identified in the generated
provenance and review manifest. Because it is a derivative of OpenNGC, the generated
`known_targets.json` is itself distributed under **CC-BY-SA-4.0** (attribution + share-alike),
not under seestar's MIT license — the file's own `provenance` block records the same source and
license. OpenNGC in turn merges data from NED, HyperLEDA, SIMBAD, HEASARC, and Harold Corwin's
NGC/IC Positions and Notes; see the upstream project and
`tools/data/openngc-v20260501/LICENSES/CC-BY-SA-4.0.txt` for the vendored license text.
