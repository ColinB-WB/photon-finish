# Styles and image versions

An **output style** describes your purpose for the photo. It is not a quality
level: every style uses the same measured processing foundation.

## Output styles

### Showcase—vivid, share-ready

The default. It aims for a bright, engaging photograph with controlled color
and contrast. Suitable extended targets may receive several star treatments,
and galaxies may receive a close-up.

Choose Showcase when you are unsure.

### Natural—restrained, realistic color

Uses a quieter presentation and restrained color. It is useful when the
Showcase result feels more vivid than you prefer.

### Reference—faithful, with annotation

Prioritizes a documentary presentation and adds an annotated JPG. This style is
useful for observing records and identifying what was captured.

### Print—tuned for paper

Prepares a brighter print-oriented presentation because paper does not emit
light like a screen. Always make a small test print before ordering a large one;
printers and papers vary.

## Image versions

A style may produce more than one version:

| Label in the app | Purpose |
|---|---|
| Recommended | Main result for the chosen style |
| Galaxy close-up | Tighter composition when the galaxy warrants it |
| Full star field | Subject with the original developed star field |
| Reduced stars | Stars made less prominent so extended structure reads more clearly |
| Starless version | Extended subject without the separated star layer |
| Annotated reference | Reference image with descriptive annotation |

Not every subject gets every version. A star cluster, for example, keeps its
stars because they are the subject. Creating unnecessary variants would add
files without adding useful choices.

## Style versus adjustment

Choose another style when you want a different overall purpose or presentation.
Use [Fine-tuning](fine-tuning.md) only when you like the style but want to change
one specific aspect of one image.
