# Create your first photo

## Before you begin

You need:

- a folder copied from your Seestar;
- at least one qualifying stacked color `.fit` or `.fits` file;
- a different folder where finished images can be saved; and
- all four helper applications installed.

The stock JPG can stay in the source folder, but the processor does not edit it.
It develops the stacked FITS because that file retains much more of the captured
data.

## Create the photo

1. Open **Photon Finish** (`Photon Finish.app` in the macOS Applications folder).
2. Under **1. Choose your Seestar photos**, select the folder you copied from
   the telescope.
3. Choose **Find photos**.
4. Under **2. Choose what to create**, select one photo.
5. Leave **Output style** set to **Showcase — vivid, share-ready**.
6. Under **3. Choose where to save**, select a folder outside the copied Seestar
   folder.
7. Choose **Create finished photo**.

The app reports its current stage and elapsed time. GraXpert and StarNet2 can
take a while, especially on the first run. Closing the app or computer during
processing stops the render.

## Review the result

The **Recommended** image is the main result. Depending on the subject, you may
also see a galaxy close-up, a full-star-field version, a reduced-star version,
or a starless version.

Below the gallery, the result check will say one of the following:

- **Ready to use** — the image passed the automatic checks.
- **Finished—capture-limited** — processing completed, but the source capture
  limits recoverable detail.
- **Needs attention** — a processing check failed; review the message before
  sharing the result.

Your files are saved under:

```text
<save folder>/<target name>/
```

Continue with [Understand the results](understanding-results.md) to learn what
was created.

## Process a whole library

After **Find photos** discovers more than one target, the Photo menu also offers
an all-photos batch. Try one target first so you can confirm the installation
and output location. A batch can take considerably longer.
