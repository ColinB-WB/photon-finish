# Installation

The canonical installation instructions are in the user manual:

**[Install the Seestar Photo Processor](docs/manual/installation.md)**

That guide covers:

- the four separately installed helper applications;
- the packaged macOS workflow;
- running from a source checkout on macOS or Windows 11 (a packaged Windows
  application is coming soon); and
- checking the installation with `seestar doctor`.

If installation fails, continue with the
[troubleshooting guide](docs/manual/troubleshooting.md).
